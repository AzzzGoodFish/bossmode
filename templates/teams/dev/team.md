# Dev Team

Bossmode's built-in product development team. Instantiate into a Room to start with a ready roster and collaboration norms.

## Roster

| Role | Owns |
|------|------|
| **pm** | Requirements, priorities, acceptance, process ownership |
| **architect** | System design, plans, merge |
| **developer** | Implementation and tests |
| **dev-ben** | Parallel implementation stream |
| **designer** | UI/UX, prototypes, visual polish |
| **qa** | Acceptance, regression, release gate |

## How we work

- Natural language first — prefer saying it over adding buttons.
- Tasks for multi-step work; chat `@name` only when you need immediate action.
- Sequential work: `@` only the first member, then hand off.
- RC-first releases; fish self-tests before formal publish.

This package is product-shipped (`type: builtin`) and may update with Bossmode releases.
